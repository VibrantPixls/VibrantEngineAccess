# Vibrant Engine Access
## How to get access

1. Get access to the Unreal Engine source code
2. Go to https://vibrantpixls.github.io/VibrantEngineAccess/
3. Scroll down and press authorize to authorize the OAuth App (the app will ONLY READ public information)
4. Accept the email invitation
