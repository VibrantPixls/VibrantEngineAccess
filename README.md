# Vibrant Engine Access
## How to get access

1. Get access to the Unreal Engine source code
2. Go to https://vibrantpixls.github.io/VibrantEngineAccess/
3. Scroll down and complete the two steps:
   1. Tick the checkbox confirming you accepted the Unreal Engine End User License Agreement and have access to the Unreal Engine source code on GitHub
   2. Open the linked commit on the Unreal Engine source code repository and enter the full file name of the changed file
4. Press "Authorize with GitHub" to authorize the OAuth App (the app will ONLY READ public information)
5. Accept the email invitation
