Vibrant Engine

Vibrant Engine is a customized fork of UnrealEngineVite

based on my personal preferred configuration

Changes

Character class improvements

  • Ready-to-use PlayerCharacter class
  • Built-in run system
  • Better default character mesh and movement settings

AI improvements

  • Ready-to-use Smooth AI Controller class
  • AI look at target pitch fix
  • Better default AI settings

Blueprint node additions

  • Tick-based delay nodes
  • Nodes backported from UE5
  • ForLoop and ForEachLoop macros with continue
  • Newly added features in blueprint usable

Engine additions

  • r.FreezeFrame console command and helpers
  • In-menu seperate fps limit options

Audio additions

  • Parent-child sound class hierarchy
  • More default controller sound classes
  • Volume settings (master, music, SFX, etc) available in the GameUserSettings
  • Newly added features in blueprint usable

Plugin additions

  • Beter plugin enable defaults (unneeded ones off, useful ones on)
  • Bundled useful plugins

Assets additions

  • Added different additions to the engine that might be handy

Visual changes

  • More vibrant default color tuning
  • Pixelated (instead of blurry) game rendering when using low-resolution scaling
  • New default materials and textures
  • Beter default rendering settings

Editor changes

  • Slightly changed visuals
  • Better default editor settings
  • Better default blueprint graph settings

Packaging changes

  • Better default settings
  • SteamPipe optimized packaging settings

Naming changes

  • Graphics preset "Epic" renamed to "Ultra"
  • "High Quality Reflections" renamed to "Parallax Corrected Reflections"

And more!
